# re:Invent Compass

**Plan like a spec. Board like a flight.**

A Kiro Power that helps first-time AWS re:Invent attendees plan their week from their own code, book it safely, and get into every reserved session on time.

> **Status:** in development for the re:Invent Event Catalog API Hackathon (October to November 2026). Setup and usage instructions will be added here as the build lands.
