_For developers: what each folder in the repository holds, which package owns what, and where to start reading the code._

re:Invent Compass is one npm workspaces monorepo. Four TypeScript packages, an Angular site and the Terraform for AWS live side by side, so a change to a shared contract is checked against every consumer in one pull request.

## The tree

```text
.
├── .github/          CI workflows, CI scripts, Dependabot
├── .kiro/            Kiro specs, steering files and the save hook
├── contracts/        the Compass API OpenAPI contract (single source)
├── data/             venues.json: the six venues and their walking times
├── fixtures/         Events API fixtures, the sample repo, the synthetic catalog
├── infra/            Terraform: bootstrap, dev and prod, six modules, tests
├── packages/
│   ├── contracts/    @compass/contracts: zod schemas, generated types, MCP tool schemas
│   ├── core/         @compass/core: Events API client, rules, scanner, planner, passes
│   ├── mcp-server/   reinvent-compass: the local MCP server and CLI (the npm package)
│   └── pass-service/ @compass/pass-service: the two Lambda functions of the pass API
├── power/            the Kiro Power: manifests, skills, hook template
├── scripts/          owner-run deploy and secret scripts
├── site/             @compass/site: the Angular showcase site
├── spikes/           code kept from the technical spikes
├── CONCEPT.md, KIRO-SPEC-PROMPTS.md, README.md, CONTRIBUTING.md, SECURITY.md
├── LICENSE, NOTICE
├── package.json, package-lock.json, tsconfig.json, tsconfig.base.json
├── vitest.config.ts, eslint.config.js, .prettierrc.json
└── .nvmrc, .npmrc, .env.example, .gitleaks.toml, .trivyignore
```

The workspaces are declared in the root [package.json](https://github.com/henniefrancis/aws-re_invent-compass/blob/develop/package.json): [packages/contracts](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/contracts), [packages/core](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core), [packages/mcp-server](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/mcp-server), [packages/pass-service](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/pass-service) and [site](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/site).

## Packages

### packages/contracts

[packages/contracts](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/contracts) is `@compass/contracts`, the shared shapes every other package imports. It has one export (`.`).

| Path                                                                                                                                            | What it holds                                                                                     |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| [src/wire](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/contracts/src/wire)                                     | zod schemas for the Events API wire shapes: session, schedule, event, personal time, bulk result. |
| [src/domain](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/contracts/src/domain)                                 | Compass domain shapes: commitment, normalised session, venue, verdict.                            |
| [src/generated](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/contracts/src/generated)                           | TypeScript types generated from both OpenAPI documents. Never edited by hand.                     |
| [src/mcp-tools.ts](https://github.com/henniefrancis/aws-re_invent-compass/blob/develop/packages/contracts/src/mcp-tools.ts)                     | The input and output schema of all 24 MCP tools.                                                  |
| [src/compass-api-schemas.ts](https://github.com/henniefrancis/aws-re_invent-compass/blob/develop/packages/contracts/src/compass-api-schemas.ts) | zod schemas for the Compass API responses, typed against the generated types.                     |
| [events-api.openapi.json](https://github.com/henniefrancis/aws-re_invent-compass/blob/develop/packages/contracts/events-api.openapi.json)       | The official [Events API](Glossary#events-api) OpenAPI document.                                  |
| [openapi.yaml](https://github.com/henniefrancis/aws-re_invent-compass/blob/develop/packages/contracts/openapi.yaml)                             | A byte-identical copy of the Compass API contract, the input for type generation.                 |

### packages/core

[packages/core](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core) is `@compass/core`, the logic shared by the MCP server and the site. It has no root export: each area is a subpath, declared in [packages/core/package.json](https://github.com/henniefrancis/aws-re_invent-compass/blob/develop/packages/core/package.json).

| Subpath                   | Source                                                                                                           | What it does                                                                                                                                                                  |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@compass/core/auth`      | [src/auth](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core/src/auth)           | [PKCE](Glossary#pkce) sign-in with [AWS Builder ID](Glossary#aws-builder-id), the loopback callback, the keychain token store, refresh and sign-out.                          |
| `@compass/core/api`       | [src/api](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core/src/api)             | One file per Events API operation, plus the transport, retry policy, quota tracker and confirmed-write helper. See [Events API coverage](Events-API-Coverage).                |
| `@compass/core/catalog`   | [src/catalog](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core/src/catalog)     | Catalog paging, the private on-disk cache, session normalisation, local filtering and the event window.                                                                       |
| `@compass/core/simulated` | [src/simulated](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core/src/simulated) | The fixture-backed transport for [simulated mode](Glossary#simulated-mode).                                                                                                   |
| `@compass/core/rules`     | [src/rules](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core/src/rules)         | The pure, browser-safe [guardrail](Glossary#guardrail) rules: clashes, connections, boarding, energy, layovers, rebooking, safe swap. See [Guardrail rules](Guardrail-Rules). |
| `@compass/core/scanner`   | [src/scanner](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core/src/scanner)     | The read-only repository scanner: AWS services and other technology.                                                                                                          |
| `@compass/core/spec`      | [src/spec](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core/src/spec)           | The week planner and the writer of the week plan as a Kiro spec.                                                                                                              |
| `@compass/core/passes`    | [src/passes](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core/src/passes)       | The pass fields builder, the Compass API client, pass sync, QR codes and the calendar file.                                                                                   |
| `@compass/core/redact`    | [src/redact](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core/src/redact)       | The single redactor used before anything is logged.                                                                                                                           |
| `@compass/core/github`    | [src/github](https://github.com/henniefrancis/aws-re_invent-compass/tree/develop/packages/core/src/github)       | The [GitHub App](Glossary#github-app) device sign-in, token store and read-only repository scan.                                                                              |

Each subpath has a `@compass/source` export condition that points at the TypeScript source. Vitest resolves that condition, so a fresh clone runs the tests with no build step.
