# Official sources

Every page below was opened and read on 17 October 2026. Only these hosts are used: `reinvent.awsevents.com`, `aws.amazon.com` and `docs.aws.amazon.com`.

| Page                                         | URL                                                                | What it was used for                                                                                                                                                                      |
| -------------------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AWS re:Invent frequently asked questions     | https://aws.amazon.com/events/reinvent/faqs/                       | Session types, reserved seating, the ten minute arrival rule and walk-up line, repeat sessions marked with -R, the age rule for badges, the list of venues and the advice on travel time. |
| AWS re:Invent                                | https://aws.amazon.com/events/reinvent/                            | The dates (30 November to 4 December, Las Vegas) and the link to the venues and hotels page.                                                                                              |
| AWS Events app                               | https://aws.amazon.com/events/reinvent/mobile-app/                 | Where seats are reserved, how favourites and reservations show together, and syncing the schedule to a calendar.                                                                          |
| Using the AWS Events MCP server (developers) | https://docs.aws.amazon.com/events/latest/devguide/mcp-server.html | The tools of the official remote server, and that a reservation can report success for some sessions and failure for others.                                                              |

## Not covered by these pages

- Where and when badges are picked up. The FAQ page gives only the age rule.
- Whether repeat sessions use reserved seating.
- Whether Encore hosts content sessions (the FAQ lists it only in the dates section).

Do not fill these gaps from memory. Send the attendee to the official pages.
