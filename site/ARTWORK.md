# Artwork manifest

Every file in `public/` is original artwork made for this site. The site uses no AWS brand colour, and no AWS logo or AWS trademark artwork except on The Creator page: the owner's own photo shows the AWS Community Builder logo, and the owner's link images under it show the AWS Community South Africa and AWS Builder Center marks, with the LinkedIn and GitHub marks used only to link to the owner's own profiles. The owner is an AWS Community Builder and the founder of AWS Community South Africa and is allowed to use these marks (owner, 22 October 2026, tasks 34 and 35). Apart from those images, the only third-party artwork is the "Add to Apple Wallet" and "Add to Google Wallet" badges on the board page, from the vendors' official badges under their terms (owner decision of 21 October 2026, task 29). On 21 October the owner replaced both with higher-quality versions of the same official badges, sized to match the calendar button (task 31). The drawings are SVG, so they are the same on every screen; the Creator page images are the only raster images (WebP). Licence: Apache-2.0, like the rest of the repository.
