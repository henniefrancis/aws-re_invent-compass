# Artwork manifest

Every file in `public/` is original artwork made for this site. The site uses no AWS logo, no AWS trademark artwork, no Apple or Google badge artwork and no AWS brand colour. Each file is an SVG, so it is the same on every screen. Licence: Apache-2.0, like the rest of the repository.

| File                              | Used for                                                            | Author                                              | Original |
| --------------------------------- | ------------------------------------------------------------------- | --------------------------------------------------- | -------- |
| `public/artwork/favicon.svg`      | Browser tab icon (a compass)                                        | Claude, for the re:Invent Compass project (S7 site) | Yes      |
| `public/artwork/seat-release.svg` | Home page timeline: seat released at 10:20, session starts at 10:30 | Claude, for the re:Invent Compass project (S7 site) | Yes      |

The sample boarding pass in the demo is drawn as inline SVG by the site code (`src/app/pages/demo/`). It is original too, and it has no barcode, no QR code and no AWS mark.
