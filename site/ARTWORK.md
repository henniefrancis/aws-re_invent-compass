# Artwork manifest

Every file in `public/` is original artwork made for this site. The site uses no AWS logo, no AWS trademark artwork, no Apple or Google badge artwork and no AWS brand colour. The drawings are SVG, so they are the same on every screen; the one picture is a JPEG. Licence: Apache-2.0, like the rest of the repository.

| File                                 | Used for                                                                                                         | Author                                               | Original |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- | -------- |
| `public/artwork/favicon.svg`         | Browser tab icon and the Apple pass icon (the Nevada map with a road and a pin)                                  | Hennie Francis, the owner                            | Yes      |
| `public/artwork/logo.svg`            | Header logo and the Apple pass logo (the map, "2026" in a free heavy sans-serif, and "re:Invent" over "Compass") | Hennie Francis, the owner                            | Yes      |
| `public/artwork/seat-release.svg`    | Home page timeline: seat released at 10:20, session starts at 10:30                                              | Claude, for the re:Invent Compass project (S7 site)  | Yes      |
| `public/artwork/pass-background.jpg` | Board page banner; the Apple pass takes its colours from it (task 20)                                            | Hennie Francis, the owner (abstract colour gradient) | Yes      |

The sample boarding pass in the demo is drawn as inline SVG by the site code (`src/app/pages/demo/`). It is original too, and it has no barcode, no QR code and no AWS mark.
