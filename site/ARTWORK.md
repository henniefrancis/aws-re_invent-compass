# Artwork manifest

Every file in `public/` is original artwork made for this site. The site uses no AWS brand colour, and no AWS logo or AWS trademark artwork except in the owner's own photo on The Creator page, which shows the AWS Community Builder logo; the owner is an AWS Community Builder and is allowed to use it (owner, 22 October 2026, task 34). Apart from that photo, the only third-party artwork is the "Add to Apple Wallet" and "Add to Google Wallet" badges on the board page, from the vendors' official badges under their terms (owner decision of 21 October 2026, task 29). On 21 October the owner replaced both with higher-quality versions of the same official badges, sized to match the calendar button (task 31). The drawings are SVG, so they are the same on every screen; the photo is the one raster image (WebP). Licence: Apache-2.0, like the rest of the repository.
