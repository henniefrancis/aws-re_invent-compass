# Artwork manifest

Every file in `public/` is original artwork made for this site. The site uses no AWS logo, no AWS trademark artwork and no AWS brand colour. The only third-party artwork is the official "Add to Apple Wallet" and "Add to Google Wallet" badges on the board page, used unchanged under their vendors' terms (owner decision of 21 October 2026, task 29). The drawings are SVG, so they are the same on every screen. Licence: Apache-2.0, like the rest of the repository.

| File                               | Used for                                                                                                           | Author                                                                                                           | Original    |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ----------- |
| `public/artwork/favicon.svg`       | Browser tab icon and the Apple pass icon (the Nevada map with a road and a pin)                                    | Hennie Francis, the owner                                                                                        | Yes         |
| `public/artwork/logo.svg`          | Header logo and the Apple pass logo (the map, "2026" in a heavy system sans-serif, and "re:Invent" over "Compass") | Hennie Francis, the owner                                                                                        | Yes         |
